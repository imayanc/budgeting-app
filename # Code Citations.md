# 💸 Budget App HTML Explained (The Fun Way) 

```html
<!DOCTYPE html>
<html lang="en">
```
🎬 **Opening Credits** - "Yo, this is HTML5, not some ancient XHTML nonsense from 2003!"

---

```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Simple Budget App</title>
    <link rel="stylesheet" href="style.css">
</head>
```
🧠 **The Brain Section** - Setting up the vibes:
- `charset="UTF-8"` → "Accept all the weird symbols, bro 🌍"
- `viewport` → "Hey mobile users, we got you covered 📱"
- `<title>` → What shows up in the browser tab (don't name it "Untitled" like a monster
